# scripts

Расчёт геометрии круга. Значения `a`/`c`/`hex` в `../data.js` не выставлены
на глаз — они посчитаны отсюда. Нужен только python3 (без зависимостей).

- **analyze.py** — sRGB ↔ OKLCh, охват гаммы, шкала «тон → угол круга».
  Таблица `P` — исходные выкраски пигментов.
- **analyze2.py** — итоговые углы и насыщенности пигментов.
  Запуск: `python3 analyze2.py` → печатает строки для `PIGMENTS`.
- **theory.py** — цвета 12 секторов теоретического круга по той же
  искажённой шкале углов (`ANCHORS`), поэтому комплемент = сектор напротив.
  Запуск: `python3 theory.py` → печатает `THEORY` и `THEORY_LABELS`.

Поменял `ANCHORS` или состав красок — перезапусти и перенеси вывод в `data.js`.
